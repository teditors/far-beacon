# Far Beacon

A first-person survival-exploration roguelike that runs in a browser. Cross a generated land, learn
what its lost people left behind, and carry a relic to where it belongs.

```
npm install          # once
npm run build        # writes dist/index.html, the whole game in one page
npm run check        # all tests, including a browser test (needs Python Playwright)
```

Read ARCHITECTURE.md before changing anything large.
